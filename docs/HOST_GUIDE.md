# מדריך מנחה (טיוטה — יתעדכן אחרי החזרה הגנרלית)

## לפני האירוע
1. מחשב הקרנה: לפתוח `/screen` במסך מלא (F11).
2. טלפון מנחה: לפתוח `/host` ולהתחבר.
3. ליצור משחק **ניסיון**, להריץ סבב או שניים עם 2–3 טלפונים, ואז **איפוס** (שני שלבים: כפתור, ואז הקלדת "איפוס").
4. בערב עצמו: **ארכוב** משחק הניסיון, ואז יצירת משחק **אמיתי**.

## מחזור של סבב
| שלב | כפתור | מה רואים על המסך |
|---|---|---|
| הוראות | (אוטומטי במעבר סבב) | שם הסבב וההוראות |
| הימור (סבב 31 בלבד) | פתיחת הימורים ← נעילת הימורים | המסלולים, בלי החידה |
| פתוח | פתיחת הסבב | התוכן, טיימר, x/y קבוצות שלחו |
| השהיה | השהיה / המשך | "מושהה". הזמן שנשאר נשמר |
| סגור | סגירת הגשות | "הזמן נגמר" |
| נבדק | בדיקה אוטומטית | "התשובות נבדקו" |
| נחשף | חשיפת פתרון וניקוד | הפתרון. הטבלה רק אם לוחצים "הצגת טבלת דירוג" |

- **תשובות לא ודאיות** (שגיאת הקלדה קטנה) מופיעות לך להכרעה: לקבל או לדחות. בלי הכרעה אי אפשר לסיים את הבדיקה.
- **הגשה שמגיעה אחרי הזמן** (יותר מ־1.5 שניות) נשמרת לתיעוד, אבל לא מקבלת ניקוד.

## אחרי סבב 8
1. חשיפה, ואז **חישוב חלופות גמר**.
2. במסך הניהול רואים: ניקוד החמישייה, פערים, פרסי מקום 1 ו־2 בכל חלופה, ומי יכולה לזכות בכל תרחיש.
3. **בחירת חלופה**. אחרי האישור אי אפשר לשנות.
4. מעבר לשמש, פתיחה, סגירה, בדיקה, חשיפה, ואז **סיום והכרזה**.

## תקלות
- **קבוצה החליפה טלפון**: בטלפון החדש בוחרים "טלפון נוסף לקבוצה" ומזינים את קוד הקבוצה (4 ספרות, מופיע בטלפון הראשי). העברת תפקיד הקפטן: `host_set_captain` (כפתור בממשק עוד יתווסף).
- **המסך תקוע**: לרענן. הכול נטען מחדש מהשרת.
- **הטלפון שלך נכבה**: להיכנס ל־`/host` מכל מכשיר אחר.
